EXPERIMENT 9 - MODERN USER INTERFACE DESIGN USING REACTJS
KIDS LEARNING WEBSITE

This project is prepared from the uploaded Ex 9.docx lab record.
It includes React functional components, props, useState, responsive CSS,
subject cards, learning activities, progress tracking, and theme switching.

FILES
- index.html: Complete application (HTML, CSS and React code).
- README.txt: Run instructions.

HOW TO RUN
1. Download and extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
   You can also open the folder in VS Code and use the Live Server extension.
4. Keep an internet connection active because React, ReactDOM, and Babel
   are loaded using the CDN links specified in the lab document.

TEST THESE FEATURES
- Use Home, Subjects, and Activities navigation.
- Click Start Learning on a subject card.
- Switch between Light and Dark themes.
- Add a new learning activity.
- Tick a checkbox to mark an activity completed.
- Click X to delete an activity.
- Check that the completed count and progress bar update.

NOTE
Activities are held in React state and reset to the sample list when the page
is refreshed. This is suitable for the simple lab exercise.
